# Mi Blog de Aprendizaje

Blog personal que he hecho como Actividad de la universidad.

## ¿Como verlo?

Está desplegado en GitHub Pages:

**https://jalvuso.github.io/mi-blog/**

También se puede abrir en local descargando el proyecto y haciendo
doble clic en `index.html`. No hace falta instalar nada más.

## ¿Que se uso en el proyecto?

- HTML5.
- CSS3.
- JavaScript.
- Bootstrap (para el diseño y el modal).
- jQuery (para manejar el DOM y los eventos).

## ¿Qué hace?

- Muestra 3 entradas en forma de tarjetas.
- Tiene un buscador que filtra las entradas mientras escribes.
- Al hacer clic en una entrada se abre en una ventana con el
  contenido completo.
- Formulario de contacto con validación (no envía nada).
- Diseño responsive, se adapta a móvil.
